h1. Memverse

A Bible memorization application.

!https://circleci.com/gh/avitus/Memverse.svg?style=svg!:https://circleci.com/gh/avitus/Memverse

h2. Prerequisites

* Ruby 3.2.6 (RVM; see @.ruby-version@)
* Rails 7.2 (installed by @bundle install@)
* MySQL (development database @memverse_development@, test database @memverse_test@)
* Redis (Sidekiq queues and ephemeral quiz state)
* Sphinx (Thinking Sphinx full-text search)
* Node.js (asset precompilation and the JavaScript tests)

h2. First-time setup

# Install Ruby 3.2.6 (@rvm install 3.2.6@) and Node.js, and make sure MySQL and Redis are installed.
# Start MySQL (@brew services start mysql@ or your distribution's service).
# Run @./bin/setup@: it installs the gems with Bundler and creates, migrates and seeds the development and test databases (@bin/rails db:prepare@).
# Run @npm ci@ to install the JavaScript test dependencies.
# Ask a maintainer for @config/master.key@ if you need the encrypted credentials (Postmark, production database); development runs without it.

h2. Running the application

@./bin/dev@ starts MySQL and Redis if needed, then the Rails server, the Sidekiq scheduler and a Sidekiq worker through foreman (see @Procfile@). @./bin/shutdown@ stops everything and @./bin/status@ reports what is running.

h2. Running tests

All three suites must pass before any change is considered done.

* Unit tests: @bundle exec rspec@
* Integration tests: @bundle exec cucumber features@
* JavaScript tests: @npm run test:run@ (single pass; @npm test@ starts Vitest in watch mode)

h2. Configuration

This project uses the Rails credentials system for sensitive configuration (database password, Postmark API token, @secret_key_base@). To edit credentials:

@EDITOR="nano" rails credentials:edit@

The master key (@config/master.key@) is required for decryption and must never be committed.
